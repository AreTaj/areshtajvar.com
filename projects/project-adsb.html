SIGINT Machine Learning

ADS-B Telemetry Anomaly Detector

Real-time aerospace telemetry ingestion and unsupervised anomaly detection pipeline.

Interactive Demo

Context & Problem

Aircraft constantly broadcast their GPS position and velocity via Automatic Dependent Surveillance-Broadcast (ADS-B). However, in high-conflict regions like the Baltic Sea and Eastern Mediterranean, telemetry data is frequently jammed or spoofed, resulting in impossible trajectories and altitude readings.

Architecture & Approach

I engineered a localized Python pipeline to ingest live flight telemetry from the OpenSky Network API. To calculate ground speed dynamically across sequential API queries, I built a stateful tracking system backed by a local SQLite database.

To identify anomalous behavior, the pipeline filters out physical impossibilities (e.g., ground speed exceeding Mach 1) and applies an unsupervised machine learning model. Specifically, it fits an Isolation Forest model to detect statistical outliers in barometric versus geometric altitude discrepancies and normalized velocity vectors.

Key Results

  • The ingestion pipeline continuously queries the OpenSky Network API and maintains stateful trajectory records in a local SQLite database.
  • An unsupervised Isolation Forest model flags GPS jamming and spoofing anomalies across multi-dimensional kinematic features.
  • Interactive Folium maps render spatial flight paths with color-coded classifications distinguishing normal flight corridors from spoofed trajectories.
